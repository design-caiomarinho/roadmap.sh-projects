# Changelog Component

**🇪🇸 Español**

Página de changelog de Lume, un producto ficticio, basada en el proyecto [Changelog Component](https://roadmap.sh/projects/changelog-component) de roadmap.sh.

**🇧🇷 Português**

Página de changelog do Lume, um produto fictício, baseada no projeto [Changelog Component](https://roadmap.sh/projects/changelog-component) do roadmap.sh.

## Qué incluye / O que tem

**🇪🇸 Español**

- Header con logo y navegación.
- Título de la página con enlaces de RSS y correo.
- Línea de tiempo con cuatro versiones, cada una con fecha, número de versión y listas de novedades, mejoras y correcciones.
- Footer con enlaces.

**🇧🇷 Português**

- Header com logo e navegação.
- Título da página com links de RSS e e-mail.
- Linha do tempo com quatro versões, cada uma com data, número da versão e listas de novidades, melhorias e correções.
- Rodapé com links.

## Qué se practicó / O que foi praticado

**🇪🇸 Español**

- **HTML:** estructura semántica, `time` con `datetime`, `figure` y `figcaption`, `aria-label` en las navegaciones e imagen decorativa con `alt` vacío.
- **CSS:** variables, box model, selectores y especificidad, flexbox en el header, el hero y el footer, grid y pseudoelementos (`::before` y `::after`) para la línea de tiempo, y media query en 640px.

**🇧🇷 Português**

- **HTML:** estrutura semântica, `time` com `datetime`, `figure` e `figcaption`, `aria-label` nas navegações e imagem decorativa com `alt` vazio.
- **CSS:** variáveis, box model, seletores e especificidade, flexbox no header, no hero e no footer, grid e pseudo-elementos (`::before` e `::after`) para a linha do tempo, e media query em 640px.
