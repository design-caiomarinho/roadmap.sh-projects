# Testimonial Card

**🇪🇸 Español**

Sección de testimonios con una tarjeta de cliente y modo oscuro, hecha solo con HTML y CSS.

**🇧🇷 Português**

Seção de depoimentos com um card de cliente e modo escuro, feita só com HTML e CSS.

## Qué incluye / O que tem

**🇪🇸 Español**

- Título de la sección con overline e ícono.
- Tarjeta con foto, nombre, cargo, contador, servicios y botones de navegación.
- Panel con la cita del cliente.
- Botón flotante para cambiar entre modo claro y oscuro, sin JavaScript.
- Diseño adaptable para escritorio, tablet y móvil.

**🇧🇷 Português**

- Título da seção com overline e ícone.
- Card com foto, nome, cargo, contador, serviços e botões de navegação.
- Painel com a citação do cliente.
- Botão flutuante para alternar entre modo claro e escuro, sem JavaScript.
- Layout responsivo para desktop, tablet e mobile.

## Qué se practicó / O que foi praticado

**🇪🇸 Español**

- **HTML:** estructura semántica, `article`, lista de descripción (`dl`, `dt`, `dd`), `aria-label` en los botones, SVG decorativos con `aria-hidden` y checkbox accesible para el cambio de tema.
- **CSS:** variables como tokens de diseño, reset, clases de tipografía, flexbox, `flex-wrap` para reorganizar la tarjeta, `object-fit`, `:has()` para el modo oscuro y el foco del toggle, `:focus-visible`, `prefers-reduced-motion` y media queries en 1240px y 768px.

**🇧🇷 Português**

- **HTML:** estrutura semântica, `article`, lista de descrição (`dl`, `dt`, `dd`), `aria-label` nos botões, SVGs decorativos com `aria-hidden` e checkbox acessível para a troca de tema.
- **CSS:** variáveis como tokens de design, reset, classes de tipografia, flexbox, `flex-wrap` para reorganizar o card, `object-fit`, `:has()` para o modo escuro e o foco do toggle, `:focus-visible`, `prefers-reduced-motion` e media queries em 1240px e 768px.
